# 比賽版不做：第二關點子

依 SPEC 第 5 節，比賽期間不製作第二關。以下只有未驗證的設計方向，不是工作承諾，也不加入本次實作。

## 方向一：黏住與滑動之間

- **SHIFT 變成什麼：** 場地在「吸附」與「滑動」兩種接觸狀態之間自動切換。吸附時球較快留在落點，滑動時留在場上的球一起脫離束縛。
- **和第一關差在哪：** 第一關透過同頻與低摩擦放大整體爆發；此方向讓停球位置本身成為下一次換相時的起跑線，玩家押的是球群留在哪裡。
- **為什麼不是單純加數字：** 改變球與地面的關係、蓄積與釋放的節奏，而非增加 HP、球速或敵人數量。必須避免變成精準落點算題，仍維持扇形下注。

## 方向二：牆成為出口

- **SHIFT 變成什麼：** 一般狀態撞牆反彈；換相時一對相對邊界短暫接通，球從一側離開、從對側帶著動量回來。
- **和第一關差在哪：** 球場的連通關係會變，原本彼此很遠的球群在換相後可能相遇。只改邊界，不增添怪物 AI。
- **為什麼不是單純加數字：** 玩家對距離與方向的直覺會重組，連鎖能跨過場地接起來；提高爆發半徑無法產生同樣的回流路徑。需用清楚入口／出口光線避免球像憑空消失。

## 方向三：核心變成共鳴橋

- **SHIFT 變成什麼：** 一般狀態核心是靜止碰撞靶；相變時核心短暫變成能傳遞共振的節點，接到一側的震盪後，向另一側球群傳出點燃脈衝。
- **和第一關差在哪：** 第一關主要由球彼此傳遞連鎖，此方向讓中央遮擋物在換相後成為跨區傳遞的橋；玩家押核心附近或遠端群聚的位置。
- **為什麼不是單純加數字：** 同一物件的功能從阻擋變為連通，改變連鎖的空間關係。脈衝只按物理事件觸發，不增加敵人行為或手動施放時機。

## 不確定

三個方向都未實作、未試玩，也未證明比第一關更有趣。任何方向都需先由使用者決定，並另驗證是否仍保有「下注」而不是「算題」的感受。
