## 推論：建議補上的音效

全數優先使用 WebAudio 程式合成，不使用語音、旁白或背景音樂。若改用素材，必須逐項留存授權與允許散布的證據；目前不採購、不下載素材。

| 觸發事件 | 想要的感覺 | 建議的合成做法 |
|---|---|---|
| 拖拉開始與取消 | 小幅蓄緊、取消時自然放鬆；不暗示可變力道 | 三角波低音加短帶通噪聲，固定上限、取消時 50 ms 淡出 |
| 玻璃／金屬碰撞 | 一聽就能分辨材質，但不比爆發突出 | 玻璃用兩至三個非整數比正弦模態；金屬加入高頻非諧波分音；依速度控制增益與衰減 |
| ignite：連鎖傳遞 | 聲音沿著球群接棒 | 極短正弦脈衝，頻率隨深度有限度上升；按碰撞 x 位置輕量立體聲定位，密集時合併 |
| interference：異頻干擾 | 暫時絆住、失去同步 | 相近雙正弦形成 8–12 Hz 拍頻，快速低通並縮短尾音，不靠大音量警告 |
| amplified：同頻放大 | 比一般 burst 更厚、更開闊 | 疊加低八度三角波與短帶通噪聲，延長 80 ms 尾音；不只調大音量 |
| damage：核心受擊 | 能辨認「撞核心」和「撞牆」 | 低頻正弦敲擊加中頻短金屬分音；沿用短時間合併，避免每個傷害字都發聲 |
| wave：怪物出現 | 有壓力但不驚嚇 | 兩顆短促木質敲擊，以帶通噪聲與低三角波合成；負值升壓事件改節奏而非音量 |
| 相變持續、末段與釋放保護 | 整場同頻，然後一致落下 | 低音量雙正弦聲床，末段提高調變速率；release 保留專用聲部或高優先級，避免被 burst 擠掉 |
| 勝利／失敗狀態變更 | 簡短、清楚收束 | 兩至三個正弦／三角音組成上行或下行終止式，總長不超過一秒，狀態變更只播放一次 |

## 不確定與驗收邊界

本輪為音效清單，未修改音訊程式，也未進行耳機／喇叭聆聽或主觀響度驗收。音高與時長來自程式；「不足」與新音色是待試聽的建議，不是已證實的聽感缺陷。3D 原型依範圍保持無音效。
