# Resonance

把每一顆球留在場上，讓碰撞累積成共振，再看整座球場一起 SHIFT。

## 怎麼玩

從下方發射圈朝場內拖拉再放開。你選擇大致方向，力道固定，實際方向會在扇形內稍微偏移；射出的球不會消失，停下後仍能被後來的球撞醒。

碰撞讓球逐漸亮起，進入共振後再次碰撞就會爆發，點燃附近的球。同頻的共振球互撞會放大爆發，異頻則會彼此干擾。當多顆球同時共振，球場自動相變：所有球同頻流動、摩擦降低，最後一起釋放。

用碰撞與連鎖清空中央 Boss 的 HP 即可獲勝；場上怪物超過十隻就失敗。連鎖回放會記下參與球號、層數、擊殺與 Boss 傷害。網頁版預計直接在 itch.io 遊玩。

## 操作

| 操作 | 功能 |
|---|---|
| 滑鼠左鍵從下方發射圈朝場內拖拉、放開 | 選方向並發射；不靠拖拉距離加力 |
| 左、右方向鍵 | 調整發射方向；先讓場地取得焦點 |
| 空白鍵 | 發射 |
| 開始畫面的夜光／紙本／極簡 | 選擇呈現風格 |
| 音效按鈕 | 開啟或關閉音效 |
| 重來 | 回到開始畫面 |
